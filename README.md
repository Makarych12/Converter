# Convector — Next-Gen Online Currency Converter

Бессерверный (client-side) конвертер валют, криптовалют и драгметаллов. PWA, офлайн, без сборки и без зависимостей.

## Запуск

```bash
npm start          # = python3 -m http.server 8080
# открыть http://localhost:8080
npm test           # юнит-тесты парсера и форматирования (node --test)
```

Нужен любой статический HTTP-сервер: через `file://` ES-модули и Service Worker не работают.
Для деплоя достаточно залить папку на любой статический хостинг (Vercel, Netlify, GitHub Pages, nginx).
PWA и `navigator.clipboard` требуют HTTPS (или `localhost`).

## Как устроены данные

Все курсы хранятся как «единиц валюты за 1 EUR», конвертация идёт через EUR-кросс.

1. **Fawazahmed0** (jsDelivr, запасное зеркало — Cloudflare Pages) даёт базу из 300+ кодов.
2. **Frankfurter / ЕЦБ** перекрывает ~30 основных валют официальными курсами.
3. **CoinGecko** перекрывает цены криптовалют.

Источники опрашиваются параллельно (`Promise.allSettled`). Если какой-то из них недоступен, его валюты берутся из предыдущего снапшота. Курсы обновляются каждые 5 минут, пока вкладка активна.

**История для графика:** пары из ЕЦБ берутся у Frankfurter (с 1999 года), крипта — у CoinGecko (бесплатный API отдаёт максимум 1 год), остальной фиат и металлы — из дневных снапшотов Fawaz (с марта 2024). Дневные снапшоты неизменны и кэшируются в IndexedDB навсегда.

**Ограничения:** у ЕЦБ нет внутридневных данных, поэтому для чистого фиата режим «24ч» показывает последние фиксинги (интерфейс об этом предупреждает). Лев (BGN) с 2026 года привязан к евро (1,95583), так что его график — горизонтальная линия.

## Производительность на слабых устройствах (v1.1)

Целевые устройства — Honor 20/40 Lite и бюджетные Android (Mali / MediaTek / Kirin Lite).

- **Лёгкий режим (`html.lite`)** включается инлайн-скриптом в `<head>` до первой отрисовки. Условия: сенсорный ввод, ≤ 4 ГБ ОЗУ или ≤ 4 ядер. В этом режиме у панелей нет `backdrop-filter` (главный источник фризов при скролле), фон не анимируется, тени облегчены, у спарклайнов нет градиентной заливки, у графика ≤ 240 точек.
- **Фон:** размытые пятна сделаны через `radial-gradient` вместо `filter: blur(90px)`. Анимация фона работает только на десктопе.
- **Ввод:** пересчёт сетки 1→N склеивается в один проход на кадр через `requestAnimationFrame`. В DOM пишется только то, что изменилось. Роли, курсы и спарклайны пересчитываются лишь при смене пары или курсов.
- **Сетка:** вставка идёт одним `DocumentFragment`. Карточки изолированы через `contain`, а карточки за экраном не рендерятся (`content-visibility: auto`).
- **Ленивые графики:** спарклайны рисуются только для карточек в зоне видимости (`IntersectionObserver`). Большой график загружается и рисуется, когда панель приближается к экрану. История за 7 дней грузится в `requestIdleCallback`. События `pointermove` на графике обрабатываются не чаще одного раза за кадр.
- **Парсер:** регулярки скомпилированы один раз на модуль, числа разбираются по кодам символов, есть LRU-кэш на 64 выражения.
- **Хранилище:** состояние сериализуется один раз и пишется в простое, только если изменилось. Дубль снапшота курсов в IndexedDB убран.
- **Service Worker:** регистрируется после `load` в простое. Запись в Cache Storage не задерживает ответ. Неизменные датированные снапшоты в Cache Storage не дублируются, они уже лежат в IndexedDB.

## Установка PWA

Кнопка «Установить» показывается только на десктопе: мышь или тачпад (`(hover: hover) and (pointer: fine)`), не мобильный UA, не iPadOS, и сработало событие `beforeinstallprompt`. На телефонах и планшетах событие не перехватывается, поэтому установка доступна через штатное меню браузера.

## Горячие клавиши

- `/` или `Ctrl+K` — добавить валюту
- `Enter` в поле — свернуть выражение в результат (`100*2` → `200`)
- `↑ / ↓ / Enter` — навигация в окне выбора валюты

## Обновление PWA

Service Worker отдаёт оболочку по стратегии stale-while-revalidate. После деплоя новой версии поменяйте `VERSION` в `sw.js` (сейчас `v2`), чтобы сбросить старый кэш.
