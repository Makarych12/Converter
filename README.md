# Convector — Next-Gen Online Currency Converter

Бессерверный (client-side) конвертер валют, криптовалют и драгметаллов. PWA, офлайн, без сборки и без зависимостей.

## Запуск

```bash
npm start          # = python3 -m http.server 8080
# открыть http://localhost:8080
npm test           # юнит-тесты парсера и форматирования (node --test)
```

Нужен любой статический HTTP-сервер: через `file://` ES-модули и Service Worker не работают.
Для деплоя достаточно залить папку на любой статический хостинг (Vercel, Netlify, GitHub Pages, nginx).
PWA и `navigator.clipboard` требуют HTTPS (или `localhost`).

## Как устроены данные

Все курсы хранятся как «единиц валюты за 1 EUR», конвертация идёт через EUR-кросс.

1. **Fawazahmed0** (jsDelivr, запасное зеркало — Cloudflare Pages) даёт базу из 300+ кодов.
2. **Frankfurter / ЕЦБ** перекрывает ~30 основных валют официальными курсами.
3. **CoinGecko** перекрывает цены криптовалют.

Источники опрашиваются параллельно (`Promise.allSettled`). Если какой-то из них недоступен, его валюты берутся из предыдущего снапшота. Курсы обновляются каждые 5 минут, пока вкладка активна.

**История для графика:** пары из ЕЦБ берутся у Frankfurter (с 1999 года), крипта — у CoinGecko (бесплатный API отдаёт максимум 1 год), остальной фиат и металлы — из дневных снапшотов Fawaz (с марта 2024). Дневные снапшоты неизменны и кэшируются в IndexedDB навсегда.

**Ограничения:** у ЕЦБ нет внутридневных данных, поэтому для чистого фиата режим «24ч» показывает последние фиксинги (интерфейс об этом предупреждает). Лев (BGN) с 2026 года привязан к евро (1,95583), так что его график — горизонтальная линия.

## Горячие клавиши

- `/` или `Ctrl+K` — добавить валюту
- `Enter` в поле — свернуть выражение в результат (`100*2` → `200`)
- `↑ / ↓ / Enter` — навигация в окне выбора валюты

## Обновление PWA

Service Worker отдаёт оболочку по стратегии stale-while-revalidate. После деплоя новой версии поменяйте `VERSION` в `sw.js`, чтобы сбросить старый кэш.
